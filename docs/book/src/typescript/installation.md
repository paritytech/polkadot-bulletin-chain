# Installation

Install the package via your package manager:

```bash
npm install @parity/bulletin-sdk
# or
yarn add @parity/bulletin-sdk
# or
pnpm add @parity/bulletin-sdk
```

## Dependencies

The SDK requires Node.js 22 or later. Install its peer dependencies, Polkadot API (PAPI) and `multiformats`:

```bash
npm install polkadot-api@^3.1.0 multiformats@^14
```
